# GST Quick Reference for This Project

## Intra-State
Seller and customer are in the same state in the sample data.
The sample splits GST equally into CGST and SGST.

## Inter-State
Seller and customer are in different states in the sample data.
The sample records the GST as IGST.

## Invoice Formula
Taxable Value = Quantity × Unit Price
GST = Taxable Value × GST Rate
Invoice Total = Taxable Value + GST

This is an educational project guide, not tax advice.
